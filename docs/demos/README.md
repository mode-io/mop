# Live terminal recordings

MOP 0.9.2, recorded on a running Linux host on 2026-10-24 with the local OpenJev core placeholder.

- `mop.mp4`, `hmop.mp4`, `bmop.mp4`: memory sorting, row selection, then CPU sorting.
- `models.mp4`: navigate the current model catalog. Specialist entries connect to placeholder slots; dedicated models are coming soon.
- `overview.gif`: short excerpts from all four recordings.

The four terminal recordings above contain actual terminal frames sampled at four frames per second. Rendering restores the application's custom terminal palette. Each video is ten seconds; the GIF is a condensed preview. Displayed findings and performance counters are live values from this host.
